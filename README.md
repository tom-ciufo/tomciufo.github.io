## About Me

I am an IT and Cybersecurity graduate with a focus on Health Informatics, system architecture, and population health data analysis. My work focuses on building and analyzing healthcare data systems using modern tools and standards.

## Projects

### Public Health Disease Surveillance Architecture

This project demonstrates the design and implementation of a distributed healthcare system using multiple virtual machines, electronic health records, and interoperability standards.

Key features:

* Multi-VM healthcare system deployment
* OpenEMR electronic health record system
* HAPI FHIR server for data exchange
* Synthetic patient generation using Synthea
* REST API integration and testing using Postman

---

### Population Health GIS Mapping and Analysis

This project focuses on visualizing healthcare and population data using GIS tools to support public health decision-making.

Key features:

* Choropleth mapping using QGIS
* Hospital and population data visualization
* Spatial analysis of healthcare distribution
* Comparison of classification methods (Quantile, Equal Interval, Jenks)
